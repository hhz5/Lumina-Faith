## 📖 项目简介

**Lumina 灵境智修** 是一款旨在为现代都市人提供「即时身心收摄与心性澄澈」的数字修行空间。项目拒绝封建迷信与虚妄神化，以人类历经时间淬炼的正统心性流派为基石，结合现代认知心理学与 Web Audio 原生声学合成，提供极简、静谧、安全的日常修持工具。

## 🛠️ 技术架构

本项目基于现代前端工程化标准构建，具备轻量、无第三方重依赖、端侧高性能运行等特点：

| 层级 | 技术选型 | 作用与优势 |
| :--- | :--- | :--- |
| **视图层** | `React 18` + `TypeScript` | 强类型保障，组件生命周期高度优化 |
| **构建工具** | `Vite 5` | 毫秒级极速热重载与生产静态优化 |
| **样式系统** | `Tailwind CSS v4` | 现代宋体禅意配色系统，支持深色/浅色模式自适应 |
| **声学引擎** | `Web Audio API` 原生合成 | 零依赖音频合成器，纯数学计算生成 432Hz/580Hz/784Hz 纯净法音与白噪音 |
| **图标体系** | `Lucide React` | 统一度量与轻量矢量图标库 |
| **响应式适配** | 桌面端与移动端双模态 | 移动端原生 App 级触控体验，桌面端全景交互大屏 |

## 🚀 快速开始

### 前置要求
- Node.js (推荐 `v18.0.0` 或更高版本)
- npm 或 pnpm / yarn

### 1. 克隆代码仓库
```bash
git clone https://github.com/your-username/lumina-sanctum.git
cd lumina-sanctum
```

### 2. 安装项目依赖
```bash
npm install
```

### 3. 启动本地开发环境
```bash
npm run dev
```
打开浏览器访问 `http://localhost:3000` 即可体验完整功能。

### 4. 生产环境打包构建
```bash
npm run build
```
打包生成的高性能静态资源将输出在 `dist/` 目录中。

## 📜 伦理宪章与合规说明

Lumina 恪守严格的 **《去神化与数字心性自律宪章》**：

1. **去神化与纯净认知**：坚决将心性哲学作为认知科学与心理调适工具，绝不引入偶像崇拜、虚妄许愿、命理预测与收费赎罪券等异化功能。
